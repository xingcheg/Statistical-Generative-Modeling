Variational inference for a linear Gaussian decoder¶

Example 1 · STAT 5095 · Statistical Generative Modeling¶

This notebook implements Example 1 in Lecture 4: the Gaussian ELBO, the original closed-form variational E-step and M-step. After fitting, a QR-based rotation puts the loadings and latent variables into identifiable coordinates. We estimate the loading matrix $W$ and infer a separate latent distribution for each observation.

The model is exactly the one in the slides:

$$ Z_i\sim N(0,I_K),\qquad X_i\mid Z_i\sim N(WZ_i,I_D). $$

We use $K=2$ latent dimensions and $D=6$ observed variables. The observation-noise covariance is known and fixed at $I_D$, and the mean is known to be zero. We do not estimate an intercept or noise variance, and we do not standardize or empirically center the data.

Mathematical quantity Python variable Shape
Observations, one row per subject X $(n,D)$
Latent variables, one row per subject Z $(n,K)$
Decoder/loadings W $(D,K)$
Variational means, one row per subject mu $(n,K)$
Shared variational covariance Sigma $(K,K)$

The slides use column vectors $x_i=Wz_i+\epsilon_i$. With observations stored in rows, the same equation is X = Z @ W.T + noise.

Identifiable coordinates after fitting. For reporting and comparison, we use $D\geq K$, $W_{dk}=0$ when $d<k$, and $W_{kk}>0$ for $k=1,\ldots,K$. For a rectangular $D\times K$ matrix, this means the leading $K\times K$ block is lower triangular with positive diagonal; the remaining rows are unrestricted. For $K=2$,

$$ W=\begin{pmatrix} w_{11}&0\\ w_{21}&w_{22}\\ w_{31}&w_{32}\\ \vdots&\vdots\\ w_{D1}&w_{D2} \end{pmatrix},\qquad w_{11}>0,\quad w_{22}>0. $$

The other entries may have either sign. We simulate the true model in this form, run unrestricted variational EM, and then apply a QR-based rotation to the fitted model. With a nonsingular leading loading block, fixed observation order, and known noise covariance, this gives a unique representative of the fitted covariance. Section 6 derives the transformation.

2. Simulate training and test data¶

The true loading matrix is lower triangular with a positive diagonal. Its columns can still be nonorthogonal; triangular loadings do not require independent posterior coordinates.

Generate independent training and test samples using separate random generators. Only X_train is used to estimate $W$; the true latents and noiseless signals are retained solely for simulation evaluation.

3. The Gaussian ELBO and two coordinate updates¶

Choose $q_i(z_i)=N(\mu_i,\Sigma_i)$ with a full, positive-definite covariance. The slides give

$$ \mathcal L_i = -\frac D2\log(2\pi) -\frac12\left[\|x_i-W\mu_i\|^2+\operatorname{tr}(W^\top W\Sigma_i)\right] -\frac12\left[\operatorname{tr}(\Sigma_i)+\|\mu_i\|^2-K-\log\det\Sigma_i\right]. $$

The two bracketed terms are the expected reconstruction error and twice the KL divergence to the prior. The trace term accounts for uncertainty in $Z_i$; using only $\mu_i$ would omit it.

E-step: hold $W$ fixed and optimize each $q_i$¶

Define $A=I_K+W^\top W$. Setting the ELBO derivatives to zero gives

$$ \mu_i=A^{-1}W^\top x_i,\qquad \Sigma_i=A^{-1}. $$

All observations have the same optimal covariance in this model. We therefore store a single matrix Sigma; the $n$ means remain observation-specific. This is an exact simplification, not an extra restriction on the optimum.

M-step: hold $q_1,\ldots,q_n$ fixed and optimize $W$¶

Use the original unrestricted update from the slides:

$$ W^{\mathrm{new}}= \left(\sum_i x_i\mu_i^\top\right) \left(\sum_i[\Sigma_i+\mu_i\mu_i^\top]\right)^{-1}. $$

For the shared covariance this becomes (X.T @ mu) @ inverse(n * Sigma + mu.T @ mu). We use linear solves instead of explicit inverses. Notice the $n\Sigma$ term: the M-step uses second moments, not just posterior means.

There are no triangular or sign constraints during optimization. The fitted $W$ may have an arbitrary latent orientation. After EM finishes, we transform both the loadings and the latent coordinates together; this leaves the fitted distribution unchanged.

def e_step(X, W):
    """Optimal full-Gaussian q for every row of X, at the current W."""
    K = W.shape[1]
    A = np.eye(K) + W.T @ W
    Sigma = np.linalg.solve(A, np.eye(K))
    mu = np.linalg.solve(A, (X @ W).T).T
    return mu, Sigma

def m_step(X, mu, Sigma):
    """Original unrestricted M-step from the slides."""
    S_xz = X.T @ mu
    S_zz = X.shape[0] * Sigma + mu.T @ mu
    # Solve W S_zz = S_xz by transposing the equation.
    return np.linalg.solve(S_zz, S_xz.T).T


def elbo_per_observation(X, W, mu, Sigma):
    """Analytic ELBO, including constants; one value per observation."""
    D, K = W.shape
    sign, logdet = np.linalg.slogdet(Sigma)
    if sign <= 0:
        raise ValueError("Sigma must be positive definite.")
    squared_residual = np.sum((X - mu @ W.T) ** 2, axis=1)
    uncertainty_term = np.trace((W.T @ W) @ Sigma)
    expected_log_likelihood = -0.5 * (
        D * np.log(2 * np.pi) + squared_residual + uncertainty_term
    )
    prior_kl = 0.5 * (
        np.trace(Sigma) + np.sum(mu ** 2, axis=1) - K - logdet
    )
    return expected_log_likelihood - prior_kl

def log_evidence_per_observation(X, W):
    """Exact marginal log density: X_i ~ N(0, W W.T + I_D)."""
    D = W.shape[0]
    C = W @ W.T + np.eye(D)
    logdet = np.linalg.slogdet(C)[1]
    precision = np.linalg.solve(C, np.eye(D))
    quadratic = np.einsum("ni,ij,nj->n", X, precision, X)
    return -0.5 * (D * np.log(2 * np.pi) + logdet + quadratic)

Why compute the evidence separately? Here $X_i\sim N(0,WW^\top+I_D)$, so we have an independent observed-data check. Most nonlinear latent-variable models do not have this convenient formula. The evidence is used for diagnostics; the M-step above uses the original ELBO update from the slides.

All objectives below are averages per observation, in natural-log units (nats). Averaging changes their scale but not the optimizer.

4. Watch one E-step and one M-step¶

Initialize $W$ randomly without triangular or sign constraints, and initialize each $q_i$ to the prior, $N(0,I_K)$. Avoid initializing $W$ to zero: then all posterior means are zero and the M-step returns zero again.

Predict what happens before running this cell:

  • The E-step changes $q$, so the evidence stays fixed while the ELBO reaches it.
  • The M-step changes $W$, so both objectives can change. The old $q$ is generally no longer the posterior for the new $W$.
  • A fresh E-step makes the bound tight again.

5. Fit $W$ by variational EM¶

Repeat the original E-step and M-step until the change in average log evidence is below $10^{-10}$, or until 1,000 iterations. This tolerance gives a precise benchmark for a small teaching example.

The history records the ELBO immediately after the M-step, using the $q$ held fixed during that step. We then perform one final E-step before returning, so the returned posterior corresponds to the returned $W$.

In a general variational EM algorithm, coordinate ascent guarantees ELBO ascent, but not necessarily observed log-likelihood ascent. In this example the E-step is exact, so both ascent properties hold, up to numerical roundoff.

The returned parameters use the unrestricted latent coordinates. The QR transformation is applied once, after fitting, in the next section.

def fit_variational_em(X, W_start, max_iter=1000, tol=1e-10):
    W = W_start.copy()
    old_loglik = log_evidence_per_observation(X, W).mean()
    history = []
    converged = False

    for iteration in range(1, max_iter + 1):
        # E-step: maximize the ELBO over the full Gaussian q's.
        mu, Sigma = e_step(X, W)
        elbo_after_e = elbo_per_observation(X, W, mu, Sigma).mean()

        # M-step: maximize the SAME ELBO over W, holding q fixed.
        W = m_step(X, mu, Sigma)
        elbo_after_m = elbo_per_observation(X, W, mu, Sigma).mean()
        loglik = log_evidence_per_observation(X, W).mean()
        history.append({"iteration": iteration, "ELBO after E": elbo_after_e,
                        "ELBO after M": elbo_after_m, "Log evidence": loglik})

        # These checks target the coordinate-ascent guarantee.
        if elbo_after_m < elbo_after_e - 1e-8 or loglik < old_loglik - 1e-8:
            raise RuntimeError("An objective decreased beyond numerical tolerance.")
        if abs(loglik - old_loglik) < tol:
            converged = True
            break
        old_loglik = loglik

    mu, Sigma = e_step(X, W)  # synchronize q with the FINAL W
    return {"W": W, "mu": mu, "Sigma": Sigma,
            "history": pd.DataFrame(history), "converged": converged}

6. QR transformation after EM¶

Keep the original unrestricted E-step and M-step. Once EM has finished, use QR on the transpose of the fitted loading matrix:

$$ \widehat W^\top=QR,\qquad Q^\top Q=I_K. $$

Here $Q$ is $K\times K$ and $R$ is $K\times D$. The first $K$ columns of $R$ form an upper-triangular block, so $R^\top$ is a $D\times K$ lower-triangular loading matrix.

Make the diagonal positive¶

QR does not automatically give a positive diagonal. Whenever $R_{kk}<0$, flip the sign of column $k$ of $Q$ and row $k$ of $R$ together. This leaves $QR$ unchanged and makes $R_{kk}>0$.

We require the first $K$ rows of $\widehat W$ to be linearly independent, so these diagonal entries are nonzero. If this condition fails, the chosen positive-diagonal convention cannot be used with that variable order.

Transform the loadings and latent variables together¶

Using the sign-adjusted $Q$ and $R$, define

$$ \boxed{W_{\mathrm{id}}=\widehat WQ=R^\top,\qquad Z_{i,\mathrm{id}}=Q^\top Z_{i,\mathrm{raw}}.} $$

Then

$$W_{\mathrm{id}}Z_{i,\mathrm{id}} =\widehat WQQ^\top Z_{i,\mathrm{raw}} =\widehat WZ_{i,\mathrm{raw}}.$$

The standard normal prior remains unchanged because $Q$ is orthogonal. The observation covariance, fitted signals, likelihood, and ELBO are preserved when the posterior is transformed together with $W$.

Why this fixes the ambiguity: if two rotation-equivalent loading matrices both have nonsingular lower-triangular leading blocks with positive diagonal, the rotation relating them must itself be lower triangular with positive diagonal. An orthogonal matrix with these properties is the identity. Thus this convention picks a unique representative, for the fixed variable order.

K = W_raw.shape[1]
if np.linalg.matrix_rank(W_raw[:K, :]) < K:
    raise ValueError("Positive-diagonal identification requires independent leading loading rows.")

# W_raw.T has shape (K, D): reduced QR gives Q (K, K) and R (K, D).
Q, R = np.linalg.qr(W_raw.T, mode="reduced")

# Flip corresponding columns of Q and rows of R to make diag(R) positive.
signs = np.where(np.diag(R) < 0, -1.0, 1.0)
Q = Q * signs
R = signs[:, None] * R

# Transform the fitted loadings AND the posterior distribution.
W_hat = R.T  # equivalently W_raw @ Q; this stores the triangular zeros exactly
mu_train = mu_train_raw @ Q
Sigma_hat = Q.T @ Sigma_raw @ Q
# Any row-stored posterior draws transform the same way: Z_new = Z_raw @ Q.

7. Held-out latent recovery¶

For new subjects, first compute the posterior under the original fitted $W_{\mathrm{raw}}$, then apply the same $Q$ to its means and covariance. This gives the same posterior as a fresh E-step using $W_{\mathrm{id}}$; the code verifies both quantities.

Compare these transformed posterior means directly with the true test latents, which were generated in the lower-triangular coordinate convention. The oracle uses the true $W$ but still only observes the noisy $X$. It is the conditional-mean benchmark, not perfect knowledge of each latent draw.

Posterior means shrink toward the prior mean. A point off the diagonal can reflect unavoidable uncertainty, not an optimization error. Fixing the latent coordinates makes this direct comparison meaningful, but does not eliminate posterior uncertainty.
