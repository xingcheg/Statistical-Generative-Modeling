2. Build the MLP¶

The network is 2 → 10 → 10 → 1: two input features, two hidden layers, and one output score (a logit). ReLU(z) = max(0, z) is applied elementwise.

Connection to “Why nonlinearity?”: without ReLU, the composition of the three affine layers would still be one affine map. More affine layers alone would not produce the curved boundary needed here.

Connection to “MLP for all subjects”: columns in the slides, rows in PyTorch.

The slides use $H^{(l)}=\phi(W^{(l)}H^{(l-1)}+b^{(l)}\mathbf 1_B^\top)$, with observations in columns. In this notebook, H stores observations in rows:

$$H_{\rm next}=\phi(HW^{\mathsf T}+\mathbf 1_B b^{\mathsf T}),\qquad H\in\mathbb R^{B\times d_{\rm in}},\quad W\in\mathbb R^{d_{\rm out}\times d_{\rm in}}.$$

Thus nn.Linear(d_in, d_out) computes H @ layer.weight.T + layer.bias. Every observation uses the same parameters; the bias broadcasts across rows.

The circle MLP¶

__init__ constructs and registers the layers. forward describes the computation. The final output is a raw logit with shape (B, 1). Set the seed before constructing the layers.

In [6]:
input_size, hidden_size1, hidden_size2, output_size = 2, 10, 10, 1
class TwoclassClassificationMLP(nn.Module):
    def __init__(self):
        super().__init__()  # Enable parameter/layer bookkeeping
        self.hidden1 = nn.Linear(input_size, hidden_size1)
        self.hidden2 = nn.Linear(hidden_size1, hidden_size2)
        self.output = nn.Linear(hidden_size2, output_size)
    def forward(self, x):
        x = F.relu(self.hidden1(x))  # (B, 10)
        x = F.relu(self.hidden2(x))  # (B, 10)
        return self.output(x)       # (B, 1), raw logits
torch.manual_seed(42)
model_1 = TwoclassClassificationMLP().to(device)

A logit is an unrestricted score; a probability lies in $[0,1]$. Do not apply sigmoid or softmax before these losses. In Example 1, $p_i=\sigma(a_i)$ and binary cross-entropy is $-y_i\log p_i-(1-y_i)\log(1-p_i)$.

Accuracy for reporting¶

Both arguments must have shape (B,). Otherwise broadcasting can accidentally compare every pair of labels. Equality gives True/False, float() converts to 1/0, and the mean times 100 gives percent accuracy. This is a reporting metric.

In [10]:
def accuracy_fn(y_true, y_pred):
    if y_true.shape != y_pred.shape:
        raise ValueError("Shapes must match.")
    return (
        (y_true == y_pred).float().mean().item() * 100)

def plot_decision_boundary(model, X, y, ax):
    """Plot a two-feature classifier without changing the model's device.

    Adapted from the original notebook's helper, credited to:
    https://madewithml.com/courses/foundations/neural-networks/
    """
    # NumPy/Matplotlib use CPU arrays; the model stays on its existing device.
    points = X.detach().cpu().numpy()
    labels = y.detach().cpu().numpy()
    parameter = next(model.parameters())

    # Build a dense grid of coordinate pairs, then predict a class at each location.
    low, high = points.min(axis=0) - 0.1, points.max(axis=0) + 0.1
    xx, yy = np.meshgrid(np.linspace(low[0], high[0], 150),
                         np.linspace(low[1], high[1], 150))
    grid = torch.as_tensor(np.column_stack((xx.ravel(), yy.ravel())),
                           dtype=parameter.dtype, device=parameter.device)

    was_training = model.training
    model.eval()
    with torch.inference_mode():
        logits = model(grid)
        # Choose from the OUTPUT shape; observed labels might omit a class.
        if logits.shape[-1] == 1:
            predicted = (logits.squeeze(-1) >= 0).long()
        else:
            predicted = logits.argmax(dim=1)  # Softmax does not change the argmax.
    model.train(was_training)  # Restore the caller's previous train/eval setting.

    regions = predicted.cpu().numpy().reshape(xx.shape)
    ax.contourf(xx, yy, regions, cmap="RdYlBu", alpha=0.35)
    ax.scatter(points[:, 0], points[:, 1], c=labels, cmap="RdYlBu", s=12)
    ax.set(xlabel="Feature 1", ylabel="Feature 2")
    ax.set_aspect("equal")

1.2 Split and create DataLoaders¶

Connection to “Fit, validate, then test”: use 54,000 images to update parameters, 6,000 to select the checkpoint, and the official 10,000-image test set only at the end. A DataLoader returns mini-batches and can shuffle training examples each epoch.

Batch / step / epoch: with batch size 64, one epoch has 844 updates: 843 full batches and a final batch of 48. The last batch is smaller because drop_last=False by default. num_workers=0 keeps loading simple and portable; larger values use worker processes and may improve throughput in some environments.

Datasets and data splits¶

train_data[i] retrieves one transformed image and its label. random_split returns disjoint subsets with fixed membership. Its seeded generator keeps this split independent of other random draws. The split does not stratify by class.

The Dataset supplies individual examples. 2. Build the MLP¶

Flatten the pixels, then apply 784 → 256 → 128 → 64 → 10. The final 10 entries are scores for mutually exclusive classes.

The FashionMNIST MLP¶

Flatten the pixels, then apply 784 → 256 → 128 → 64 → 10. The model returns ten logits for each image. Seed before initialization, not only before training.

In [23]:
class FashionMNIST_MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Flatten(),  # (B, 1, 28, 28) -> (B, 784)
            nn.Linear(784, 256), nn.ReLU(),
            nn.Linear(256, 128), nn.ReLU(),
            nn.Linear(128, 64), nn.ReLU(),
            nn.Linear(64, 10))  # Ten raw logits
    def forward(self, x):
        return self.net(x)
torch.manual_seed(42)
model_2 = FashionMNIST_MLP().to(device)

Flatten() changes the representation, not the batch membership. Sequential() registers the listed layers, so all their parameters are available to the optimizer. Each Linear layer already initializes its weights randomly.

For target class $y_i\in\{0,\ldots,9\}$ and logits $a_{ik}$, CrossEntropyLoss evaluates $-\log\operatorname{softmax}(a_i)_{y_i}$. The slides write this using one-hot labels; integer class indices express the same loss here. For class predictions, logits.argmax(dim=1) is sufficient. Use softmax(dim=1) only when you need the class probabilities.

3. Mini-batch training and validation¶

Train for 10 epochs as a manageable starting run (rather than the original 100). Select the checkpoint with the smallest validation loss. This is checkpoint selection over a fixed budget; early stopping would additionally stop the run after a chosen patience period without improvement.

Store scalar losses with .item(), and weight each batch mean by its size before averaging. This avoids retaining computation graphs and handles the smaller last batch.

Before FashionMNIST training¶

Run this initialization once before the epoch loop. history stores Python numbers for plotting. best_val_loss starts at infinity, so the first finite validation loss establishes the initial checkpoint. deepcopy will preserve saved weights while subsequent updates change the current model.

Evaluation across batches¶

The same helper evaluates validation or test data. Every call resets its totals and reads the device from the model. There are no gradient updates here. Multiply each mean batch loss by its batch size, sum, and divide by the total number of examples. This gives the smaller final batch the correct weight.

In [26]:
def evaluate_multiclass(model, loader, criterion):
    model.eval()  # 1 Evaluation behavior and no gradient recording.
    total_loss, total_correct, total_examples = 0.0, 0, 0
    model_device = next(model.parameters()).device
    with torch.inference_mode():  # 1 Evaluation behavior and no gradient recording.
        for images, labels in loader:  # 2 Iterate over all batches.
            images, labels = (
                images.to(model_device),
                labels.to(model_device))
            logits = model(images)
            batch_size = labels.size(0)
            total_loss += (
                criterion(logits, labels).item() * batch_size)
            total_correct += (
                (logits.argmax(dim=1) == labels).sum().item())
            total_examples += batch_size  # 3 Count examples for the final averages.
    return (total_loss / total_examples,
            100 * total_correct / total_examples)

Training loop: batches / Training loop: validation¶

For each epoch, train over all mini-batches, then validate once. Record the training loss, validation loss, and validation accuracy. Copy a checkpoint when validation loss improves. Restore the selected weights after all epochs. model_2.train() is necessary after the preceding validation call switched to evaluation mode. Ten epochs give 8,440 parameter updates.

A few practical options from the slides¶

Topic Minimal PyTorch change Key point
Adam torch.optim.Adam(model.parameters(), lr=1e-3) Replace SGD before training; tune the base learning rate on validation data
Dropout Add nn.Dropout(p=0.2) after a hidden ReLU Masks activations and rescales survivors in train(); acts as identity in eval()
He initialization nn.init.kaiming_normal_(layer.weight, nonlinearity="relu") Optional initialization before training for a layer followed by ReLU; variance is $2/d_{\rm in}$

Both examples keep the default nn.Linear initialization. If customizing initialization, zero biases are generally fine; identical hidden weights fail to break symmetry. Change one option at a time and compare validation results. Rebuild the model and optimizer before each fresh comparison.

Official API references: BCEWithLogitsLoss, CrossEntropyLoss, Dropout, and initialization.

Saving and restoring weights¶

Save the selected parameters to models/02_FashionMNIST_MLP.pth. Recreate the same architecture and layer names before loading. map_location="cpu" allows loading without the original GPU, then .to(device) places the model for prediction. Saving weights alone does not save the optimizer state or training history.

from pathlib import Path
MODEL_PATH = Path("models")
