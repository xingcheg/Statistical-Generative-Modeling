Lab: generate handwritten digits with a VAE¶

Data: MNIST · Images: 28 × 28 grayscale · Latent dimension: 32

We train a fully connected variational autoencoder, inspect held-out reconstructions, and generate new digit images by sampling latent vectors from a standard normal distribution. The architecture is 784 → 512 → 32 → 512 → 784, with separate encoder heads for the 32-dimensional posterior mean and log variance.

This lab follows the same sequence as the CelebA VAE lab: setup, data, model, loss, training, learning curves, reconstruction, and generation. It retains the fully connected architecture and Gaussian observation model from the original MNIST VAE notebook. Digit labels are used only to label figures and choose display examples, never to train the model.

By the end, you should be able to explain the two encoder heads, implement reparameterization and the KL penalty, and distinguish reconstruction from generation.

Run guide. Run the cells from top to bottom in Jupyter or Colab. A GPU is optional for this small model. The first run downloads MNIST. The default run uses 55,000 training images for 50 epochs, with separate validation and test sets. QUICK_RUN=True runs a shorter execution check; use the default setting for the main experiment. Training time and image quality depend on the hardware and fitted model. Output cells belong to the configuration used when executed; rerun all cells after changing settings.

Included outputs. This copy was executed on CPU with the default settings: 50 epochs, 55,000 training images, and latent dimension 32. Validation selected epoch 50. The reconstruction and generation figures below were computed from that trained model.

3. The fully connected VAE¶

The encoder represents a diagonal Gaussian, $$ q_\phi(z\mid x)=\mathcal N\!\left(\mu_\phi(x), \operatorname{diag}\{\exp(\ell_\phi(x))\}\right), \qquad \ell_\phi(x)=\log\sigma_\phi^2(x). $$ The mean and log-variance heads each return 32 numbers. They parameterize one distribution over a 32-dimensional latent vector. Reparameterization draws $$ \epsilon\sim\mathcal N(0,I_{32}),\qquad z=\mu_\phi(x)+\exp\{\ell_\phi(x)/2\}\odot\epsilon. $$ Gradients reach the encoder through this expression. logvar is log variance, so exp(0.5 * logvar) gives the posterior standard deviation.

Stage Operation Shape, omitting batch dimension
Input Flatten $1\times28\times28\to784$
Encoder hidden layer Linear + ReLU $784\to512$
Two encoder heads Separate linear layers $\mu\in\mathbb R^{32}$, $\ell\in\mathbb R^{32}$
Reparameterization Posterior draw $z\in\mathbb R^{32}$
Decoder hidden layer Linear + ReLU $32\to512$
Decoder output Linear + Sigmoid, then reshape $512\to784\to1\times28\times28$

The decoder receives only $z$ and returns a conditional mean image in $[0,1]$. The Gaussian observation model is $$p_\theta(x\mid z)=\mathcal N\!\left(g_\theta(z),\tau^2 I_{784}\right), \qquad \tau^2=\texttt{OBS\_VAR}.$$ The encoder learns posterior variances; the observation variance $\tau^2$ is fixed. The sigmoid bounds the conditional mean, while the Gaussian observation distribution itself has support on all of $\mathbb R^{784}$.

class VanillaVAE(nn.Module):
    def __init__(self, latent_dim=32, hidden_dim=512):
        super().__init__()
        self.latent_dim = latent_dim
        self.hidden_dim = hidden_dim
        self.encoder = nn.Sequential(
            nn.Flatten(),
            nn.Linear(784, hidden_dim),
            nn.ReLU(),
        )
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 784),
            nn.Sigmoid(),
        )

    def encode(self, x):
        features = self.encoder(x)
        return self.fc_mu(features), self.fc_logvar(features)

    @staticmethod
    def reparameterize(mu, logvar, eps=None):
        if eps is None:
            eps = torch.randn_like(mu)
        return mu + torch.exp(0.5 * logvar) * eps

    def decode(self, z):
        return self.decoder(z).reshape(-1, 1, IMAGE_SIZE, IMAGE_SIZE)

    def forward(self, x, sample=True):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar) if sample else mu
        return self.decode(z), mu, logvar

4. Reconstruction loss and KL divergence¶

For image $i$, with one reparameterized draw $z_i\sim q_\phi(z\mid x_i)$, define $$ R_i=\frac{1}{2\tau^2}\sum_{p=1}^{784}\{x_{ip}-g_\theta(z_i)_p\}^2, \qquad K_i=\frac12\sum_{j=1}^{32} \{\mu_{ij}^2+\exp(\ell_{ij})-1-\ell_{ij}\}. $$ The minibatch objective is $$\mathcal L=\frac1B\sum_{i=1}^B(R_i+\beta K_i), \qquad \beta=\texttt{BETA}.$$ For $\beta=1$, this estimates the negative ELBO up to the fixed Gaussian normalizing constant $\tfrac{784}{2}\log(2\pi\tau^2)$. With $\tau^2=0.5$, $R_i$ equals the pixel sum of squared errors. The KL is summed over latent coordinates. Both are averaged over images, including the smaller final minibatch with its correct weight.

We also report pixel MSE, $\|x_i-g_\theta(z_i)\|^2/784$, for interpretation. Using pixel MSE in the objective without changing the KL coefficient would change the reconstruction–regularization balance. The same fixed loss settings are used for training, validation, and test evaluation.

def vae_loss(x_hat, x, mu, logvar, obs_var, beta):
    sse_per_image = (x_hat - x).square().flatten(start_dim=1).sum(dim=1)
    reconstruction = (sse_per_image / (2 * obs_var)).mean()
    kl = 0.5 * (mu.square() + logvar.exp() - 1 - logvar).sum(dim=1).mean()
    loss = reconstruction + beta * kl
    mse = (sse_per_image / (IMAGE_SIZE ** 2)).mean()
    return {'loss': loss, 'reconstruction': reconstruction, 'kl': kl, 'mse': mse}

5. Train and select a checkpoint using validation data¶

Each epoch starts with model.train(). For each minibatch, move images to the model's device, clear old gradients, draw latent vectors, compute the loss, backpropagate, and update both encoder and decoder. Adam starts at learning rate 0.001; exponential decay multiplies it by 0.95 after each epoch, as in the CelebA lab.

Validation uses model.eval() and torch.inference_mode() without updating parameters. It still draws from the posterior to estimate the same VAE objective: eval() alone does not turn off reparameterization. A separate fixed noise generator makes validation comparisons repeatable without consuming the training noise stream.

The lowest validation objective selects best_vae.pt. We also save the latest checkpoint, history, settings, and periodic grids from fixed prior vectors. The test set is evaluated after checkpoint selection. Checkpoints support inference/reuse, not exact optimizer-state resume.

def train_one_epoch(model, loader, optimizer, obs_var, beta, epoch):
    model.train()
    totals = dict(loss=0.0, reconstruction=0.0, kl=0.0, mse=0.0)
    count = 0
    batches = tqdm(loader, desc=f'Epoch {epoch}', leave=False, disable=not SHOW_PROGRESS)
    for x, _ in batches:
        x = x.to(device, non_blocking=(device.type == 'cuda'))
        optimizer.zero_grad(set_to_none=True)
        x_hat, mu, logvar = model(x, sample=True)
        terms = vae_loss(x_hat, x, mu, logvar, obs_var, beta)
        if not torch.isfinite(terms['loss']):
            raise FloatingPointError('Non-finite training loss. Check inputs and learning rate.')
        terms['loss'].backward()
        optimizer.step()
        count += len(x)
        for key in totals:
            totals[key] += float(terms[key].detach()) * len(x)
    return {key: value / count for key, value in totals.items()}


@torch.inference_mode()
def evaluate_vae(model, loader, obs_var, beta, noise_seed=1001):
    model.eval()
    noise_generator = torch.Generator(device='cpu').manual_seed(noise_seed)
    totals = dict(loss=0.0, reconstruction=0.0, kl=0.0, mse=0.0)
    count = 0
    for x, _ in loader:
        x = x.to(device, non_blocking=(device.type == 'cuda'))
        mu, logvar = model.encode(x)
        eps = torch.randn(mu.shape, generator=noise_generator, dtype=mu.dtype).to(device)
        x_hat = model.decode(model.reparameterize(mu, logvar, eps=eps))
        terms = vae_loss(x_hat, x, mu, logvar, obs_var, beta)
        count += len(x)
        for key in totals:
            totals[key] += float(terms[key]) * len(x)
    result = {key: value / count for key, value in totals.items()}
    if not all(math.isfinite(value) for value in result.values()):
        raise FloatingPointError('Non-finite validation/test metric.')
    return result


@torch.inference_mode()
def sample_digits(model, num_digits=64, seed=2026):
    model.eval()
    generator = torch.Generator(device='cpu').manual_seed(seed)
    z = torch.randn(num_digits, model.latent_dim, generator=generator)
    z = z.to(next(model.parameters()).device)
    return model.decode(z).cpu()


def load_vae_checkpoint(path, model):
    checkpoint = torch.load(Path(path), map_location='cpu', weights_only=True)
    config = checkpoint['config']
    if config['latent_dim'] != model.latent_dim or config['hidden_dim'] != model.hidden_dim:
        raise ValueError('Match LATENT_DIM and HIDDEN_DIM to the checkpoint, then rebuild model.')
    if config['image_size'] != IMAGE_SIZE or config['input_range'] != [0, 1]:
        raise ValueError('Checkpoint preprocessing differs from this notebook.')
    if not math.isclose(config['obs_var'], OBS_VAR) or not math.isclose(config['beta'], BETA):
        raise ValueError('Match OBS_VAR and BETA to the checkpoint for consistent evaluation.')
    model.load_state_dict(checkpoint['model_state'])
    model.to(device).eval()
    return checkpoint

Reload the checkpoint selected by validation. The test objective still uses posterior sampling. For a stable reconstruction display, set $z=\mu_\phi(x)$ and plot $g_\theta(\mu_\phi(x))$. We report the pixel MSE for this deterministic choice separately. Because the decoder is nonlinear, decoding the posterior mean generally differs from $\mathbb E_{q_\phi(z\mid x)}[g_\theta(z)]$.

The figure uses the first test example of each digit, so the displayed examples are selected independently of reconstruction quality. Original images appear above their reconstructions.

@torch.inference_mode()
def posterior_mean_mse(model, loader):
    model.eval()
    squared_error = 0.0
    num_values = 0
    for x, _ in loader:
        x = x.to(device)
        reconstruction, _, _ = model(x, sample=False)
        squared_error += (reconstruction - x).square().sum().item()
        num_values += x.numel()
    return squared_error / num_values

8. Generate new digit images¶

Generation uses only the prior and decoder. Draw latent vectors independently of any input image: $$ z^{(1)},\ldots,z^{(64)}\overset{\mathrm{iid}}\sim\mathcal N(0,I_{32}), \qquad \widetilde x^{(i)}=g_\theta(z^{(i)}). $$ As in the CelebA lab, display the decoder's conditional mean for each prior draw. We do not add Gaussian observation noise to individual pixels. Thus these are images induced by prior latent draws; full draws from $p_\theta(x)$ would additionally sample $x\mid z$. The sampling scale is 1, matching the fitted standard-normal prior.

Change NEW_DIGIT_SEED for a different reproducible batch. The grid shows all 64 draws in order, with no quality filtering. The model is unconditional, so a requested digit label is not supplied. Some digits can be blurry or ambiguous; inspect both the learning curves and these outputs.
